# opam-packages.txt
# =================

# The complete package set of the opam switch: what opam's solver installs
# from the pinned repositories for the packages that jasmin/PIN and
# easycrypt/PIN request. build.sh compares the installed set with this list
# after every switch step and stops on any difference, so a switch that was
# changed by hand is not reused.
#
# Format: name version [tag...]. A tag linux or macos restricts a line to
# that operating system; the tag easycrypt marks a package that only
# EasyCrypt needs: one that the solver leaves out of a switch built with
# --no-easycrypt. The
# versions of coq-mathcomp-word and easycrypt are `dev`: they are pinned by
# commit in the PIN files.
